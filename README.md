# SkyrimNet DB Fixer

Инструмент с графическим интерфейсом для автоматического поиска и исправления поврежденных строк (битых символов) в базах данных **SkyrimNet**.

<img width="1381" height="887" alt="image" src="https://github.com/user-attachments/assets/c1cfd941-3743-4b66-8f90-9f4bc63e222b" />


## Особенности
* **Автоматическое сканирование**: Быстро находит все `.db` файлы в папке игры или в директории Mod Organizer 2.
* **Умный паттерн-матчинг**: Интеллектуальный поиск поврежденных символов и их автоматическое восстановление.
* **Удобный редактор**: Встроенный GUI для просмотра таблиц БД с подсветкой измененных ячеек.
* **Быстрый редактор**: Отдельный режим для починки произвольного текста "на лету" без необходимости открывать БД.
* **Безопасность**: Автоматическое создание резервных копий перед внесением изменений.

## Начало работы

### Установка (из исходников)
1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/selenter-c/SkyrimNetDBFixer.git
   cd SkyrimNetDBFixer
   ```
2. Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3. Запуск:
    ```bash
    python main.py
    ```

---

### Как пользоваться

> [!TIP]
> Убедитесь, что игра Skyrim закрыта перед запуском программы. Инструмент автоматически проверяет состояние процесса игры для предотвращения конфликтов доступа к файлам.

1. **Выбор БД**: Выберите режим (MO2 или "Оригинальная папка"), укажите путь и выберите нужный файл `.db`.
2. **Сканирование**: После открытия БД перейдите в таблицу (`events` или `memories`).
3. **Починка**: Нажмите кнопку "Найти сломанные строки".
4. **Применение**: Просмотрите список найденных ошибок. Битое кодирование будет подсвечено красным, а результат фикса — зеленым. Если программа обнаружит нераспознанный символ, он будет выделен желтым маркером.
5. **Сохранение**: Нажмите "Применить исправления", а затем "Сохранить изменения" в главном меню.

### Функционал быстрого редактора

Если у вас есть фрагмент текста (например, из логов или внешнего скрипта), который поврежден, откройте "Быстрый редактор" в главном меню.
- Просто вставьте текст.
- Нажмите **"Исправить"**.
- Используйте кнопку **"Скопировать"**, чтобы мгновенно получить готовый результат в буфер обмена.
